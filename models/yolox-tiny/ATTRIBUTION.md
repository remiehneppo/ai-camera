# YOLOX tiny lab oracle attribution and use gates

The exact official release artifact is `yolox_tiny.onnx` from YOLOX release
`0.1.1rc0`. `manifest.json` records observed bytes, SHA-256, ONNX tensor metadata,
and the approved numerical and runtime contract. Asset bytes live outside Git
at `data/oracle/yolox_tiny.onnx`.

Observed CPU runtime: ONNX Runtime 1.20.1, NumPy 1.26.4,
OpenCV Python headless distribution 4.10.0.84 (cv2 version 4.10.0),
CPUExecutionProvider. Input `images` float32 `[1,3,416,416]`; raw output `output`
float32 `[1,3549,85]`. A real zero-input inference produced that finite output.

`load_manifest(path, model_path, environment='lab')` validates metadata and
artifact integrity, not installation versions or graph execution: the detector
checks installed distribution versions, actual tensors and active provider.
Default lab loading enforces the exact official digest and size independent of
caller metadata. Altering bytes **and** editing a manifest hash cannot substitute
another artifact under the official model identity. Lab callers cannot override
the expected artifact pin.

Approved numerical tests use an explicitly isolated path:
`environment="numeric-test"` plus caller `expected_artifact={sha256,size_bytes}`.
They must identify `synthetic-yolox-numeric-test`, generated test-vector source,
and generated-test-data rights with both lab/production approval false. This
mode validates the numerical contract and caller-pinned generated bytes, not
lab clearance for any substituted weights. Replay CLI never selects this mode.
The fetch utility uses the checked-in official digest and rejects substitutions.

## Approved preprocessing correction

The official release binary was inspected with both candidate preprocessors.
The old RGB /255 ImageNet-normalized path yielded a maximum person score near
0.041706 on the approved photo, while the raw BGR path yielded near 0.78058.
The user explicitly approved the corrected preprocessing contract: public RGB
pixels are swapped once to BGR; raw 0–255 CHW float32, top-left 114 letterbox,
OpenCV bilinear resize. Manifest scale1/mean0/std1 denote no normalization.
Preprocessing source is pinned **independently** to
`6ddff4824372906469a7fae2dc3206c7aa4bbaee`,
<https://github.com/Megvii-BaseDetection/YOLOX/blob/6ddff4824372906469a7fae2dc3206c7aa4bbaee/yolox/data/data_augment.py>.
This does not claim the binary was exported by that commit. Binary release,
old-source COCO labels and per-class inclusive-pixel NMS provenance remain
unchanged. The old normalized configuration is not the approved final contract.
