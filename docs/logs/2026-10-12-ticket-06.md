# Ticket #06 — Recorder file replay giữ raw ring độc lập

Ngày: 2026-10-12. Ticket: [#06](../../.scratch/system-build-slices/issues/06-recorder-file-replay-giu-raw-ring-doc-lap.md).

## Hành động và quyết định

- CodeGraph xác nhận repo chưa có video source, recorder hoặc analytics replay consumer; implementation giữ tại `apps/edge/recorder.py`, không sửa event/server seams.
- Thêm file recorder dựa trên FFmpeg stream-copy: video nén raw không qua overlay/transcode; segment được commit cùng sidecar codec, keyframe PTS, time base, range và session. `-copyts` giữ source PTS qua mux; ring query hoạt động độc lập với replay consumer; consumer watermark chặn prune segment chưa xử lý. Actual range nêu rõ thiếu pre-roll/post-roll và các continuity gaps.
- Thêm semantic replay theo fixed PTS sampling và virtual event time. Consumer chạy đồng bộ để tạo backpressure; fast/realtime cùng sampling plan. Không đổi PTS thành wall-clock khi gọi consumer.
- Ghi `Execution: partial`: chưa có analytics/domain consumer để so domain outcomes, pin/recovery lifecycle, realtime drop/coverage workload, RTSP camera, hay target hardware.

- Đây là software file-replay baseline, chưa phải long-running recorder service/composition, camera RTSP, hay hardware evidence. Test fixture tổng hợp không chứng minh quyền dùng dữ liệu, target throughput, storage endurance, realtime drops/coverage hoặc analytics parity.
