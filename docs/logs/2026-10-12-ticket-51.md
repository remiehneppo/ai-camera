## Pre-implementation code evidence

- `FileRecorder.record_file` runs ffmpeg synchronously to EOF, then probes and atomically renames every `.segment-*.part.mkv` at `apps/edge/recorder.py:243-270`; until that loop, `segments()` sees no output.
- `replay` calls `_frames(Path(source))` and `_frames` runs `ffprobe -show_frames` producing a full JSON `list` (`recorder.py:320-354,378-387`), so it materializes whole timeline before delivery.
- Pin registry is durable SQLite and `pin_status` recomputes actual coverage from published segment metadata (`recorder.py:58-77,89-112`); segment publication must therefore remain atomic and not expose incomplete files.
- Current CLI/testing composes file recording; no live RTSP integration is part of this change.

## Implementation evidence

- New `FileRecorder.ingest()` uses ffmpeg's segment muxer and a publisher worker. Closed segments are probed, file-fsynced, renamed and then exposed only after an atomic, fsynced JSON sidecar commit. `record_file()` delegates to the same path while retaining strict file-only validation; `ingest()` accepts existing local files/FIFOs only and deliberately rejects remote URLs to prevent credentials entering subprocess argv.
- `segments()` tolerates sidecars removed by concurrent pruning. Live pins/outbox reconciliation report collecting/missing post-roll honestly until sufficient coverage; `finalize_pin()` refuses a still-collecting request unless partial is explicitly requested.
- After review, publisher classification changed from dropping the newest part on any nonzero exit to probing each closed candidate. Complete latest segment survives kill; incomplete trailer is removed. `reconcile(session_id)` repairs crash between media rename and sidecar commit idempotently. Non-incomplete probe/I/O failures preserve undecided media and surface errors rather than deleting it.
- Replay streams frame timestamp metadata from ffprobe CSV via a generator (time-base queried separately), keeps same fixed-PTS sampling arithmetic/watermark, and kills/reaps the reader on early consumer exit. This removes the full Python frame list but ffprobe `-show_frames` may buffer internally; hard process-wide memory bounds are not established.
- Base tests were red on HEAD baseline; implementation-agent report includes mutation/failure red proofs for corrections. Regressions cover live FIFO query, honest post-roll pin/outbox, kill preserving finished segment and discarding partial part, publisher failure stopping process, crash-window reconcile, sidecar commit visibility, streaming sampling and early consumer failure.
